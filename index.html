Scalar-quantized
embedding storage in Rust.

Zero-dependency, Big-Endian portable, 32-byte header, SHA-256 verified footer. 4× compression from f32 to u8 with exactly 1 disk seek and 0 heap allocations for quantized reads. Send + Sync reader, parallel search, LRU cache, batch ingestion, validation and transforms.

4× smaller

f32 (4B) → u8 (1B) per coordinate. Linear SQ8 per-dimension, clamped floor, degenerate range handled.

1 seek, 0 alloc

get_quantized_into(id, &mut [u8]) is exactly one seek + read_exact. Use a 64B stack buf for cache-line alignment.

Verified on disk

Header is 32B BE (BTCP magic, reserved 2B for 8B align), data block SHA-256 in footer, optional 4096B block padding.

Binary layout — Big-Endian

Header (32B):  MAGIC "BTCP" 4B
           major u16 BE | minor u16 BE | dims u16 BE | quant u16 BE | distance u16 BE | reserved u16 0
           vector_count u64 BE | footer_offset u64 BE

Metadata (2*dims*4B):  min_vec [f32; dims] BE  |  max_vec [f32; dims] BE
Data (count*dims*1B):  [u8; count*dims]  — continuous quantized bytes
Footer (@footer_offset):  row_ids [u64; count] BE  |  sha256 [u8; 32]  — hash of data block

Header is half a 64B cache line; footer may be padded to the next 4096B boundary with finalize_with_padding(true). All floats/ints are BE for portability. See src/header.rs and src/storage.rs.

FieldSizeNotes
MAGIC4BBTCP, checked on open
version2+2Bmajor/minor u16, default 1.0
dims / quant / distance2+2+2Bdims ≤ 65535, quant 0=Raw 1=SQ8 2=PQ, distance 0=L2 1=Cosine 2=IP
reserved2B0, aligns u64 to 8B and header to 32B
count / footer_offset8+8Bpatched on finalize()

Quick start

use bit_compact::{Quantizer, QuantType, DistanceMetric, CompactWriter, CompactReader};

let dataset = vec![vec![0.0, 1.0, 2.0], vec![3.0, 4.0, 5.0]];
let q = Quantizer::calibrate(&dataset).unwrap();

let mut w = CompactWriter::create("vectors.btcp", q, QuantType::SQ8, DistanceMetric::L2).unwrap();
for v in &dataset { w.append(v).unwrap(); }
w.finalize().unwrap();

let r = CompactReader::open("vectors.btcp").unwrap();
let mut buf = vec![0u8; r.dims()];
r.get_quantized_into(0, &mut buf).unwrap(); // 1 seek, 0 alloc
let deq = r.get_vector(0).unwrap();

Builder config

use bit_compact::{CompactConfig, QuantType, DistanceMetric};
let cfg = CompactConfig::builder(128, QuantType::SQ8, DistanceMetric::Cosine)
    .align_disk_blocks(true)
    .version(1,0)
    .build().unwrap();

Global & percentile calibration

let q_per_dim = Quantizer::calibrate(&dataset).unwrap();          // tightest
let q_global  = Quantizer::calibrate_global(&dataset).unwrap();   // uniform range
let q_pct     = Quantizer::calibrate_percentile(&dataset, 1.0, 99.0).unwrap(); // outlier-robust
let batch_q   = q_per_dim.quantize_batch(&dataset).unwrap();

Modules

errors

CompactError: IoError, InvalidMagicBytes, DimensionMismatch, CorruptedFooter, QuantizationOverflow.

quant

Quantizer::new / calibrate / quantize_vector / dequantize_vector / quantize_into / quantize_batch. Formula floor(((v-min)/(max-min))*255).

config

CompactConfig::builder, WriterConfig, ReaderConfig. Validation dims<=65535.

aligned

AlignedBuffer<ALIGN>, CacheAlignedBuffer (64B), BlockAlignedBuffer (4096B), StackBuf<N>.

distance

l2_squared, cosine_distance, dot, 4-wide unrolled, distance(metric) dispatch.

stats

evaluate(q, data) -> QuantizationReport {mse, mae, snr_db, ratio}.

search

brute_force_search, parallel_search (thread::scope), ScanIter.

cache

LruCache + CachedReader::new(reader, cap) — hot-vector LRU, hit_rate(), thread-shared.

batch

BatchWriter, parallel_calibrate, ChunkedReader, parallel_batch_search.

validate

validate(path) -> ValidationReport, quick_check, row-ids monotonic, checksum.

transform

Normalizer, Centering, Standardizer, Chain, Transform trait.

header / sha

Header::to_bytes/from_bytes 32B, Sha256 FIPS 180-4, no deps.

storage

CompactWriter + CompactReader (1-seek, Send+Sync), search, iter, get_batch.

CLI

bitcompact create/info/get/search/validate/stats — zero-dep arg parser in src/bin/bitcompact.rs.

Reader — zero-alloc pattern

let r = CompactReader::open("vectors.btcp").unwrap();
let mut qbuf = vec![0u8; r.dims()];
let mut fbuf = vec![0f32; r.dims()];
r.get_quantized_into(42, &mut qbuf).unwrap();                 // 1 seek
r.get_dequantized_into(42, &mut fbuf).unwrap();               // 1 seek
let batch = r.get_batch(&[0,1,2]).unwrap();                   // N seeks
let v: Vec<f32> = r.get_vector(42).unwrap();                   // alloc path
let r2 = CompactReader::open_unverified("vectors.btcp").unwrap();
assert!(r.verify_checksum().is_ok());

Search

use bit_compact::{distance, search};

let top3 = search::brute_force_search(&r, &query, 3, distance::l2_squared).unwrap();
let top3p = search::parallel_search(&r, &query, 3, 4, distance::l2_squared).unwrap();
let via_reader = r.search(&query, 3).unwrap(); // uses header distance metric

for hit in r.iter() {
    let (id, vec) = hit.unwrap();
}

LRU Cache

use bit_compact::{CachedReader, CompactReader};
let r = CompactReader::open("vectors.btcp").unwrap();
let cr = CachedReader::new(r, 128); // cache 128 hot vectors
let v = cr.get(42).unwrap(); // miss → 1 seek + insert
let v2 = cr.get(42).unwrap(); // hit → 0 seek
println!("hit rate {:.2}", cr.hit_rate());

Batch Ingestion

use bit_compact::{BatchWriter, parallel_calibrate};
let q = parallel_calibrate(&dataset, 4).unwrap();
let mut bw = BatchWriter::new(1024);
for v in dataset { bw.push(v); if bw.should_flush() { bw.flush_to(&mut writer).unwrap(); } }
bw.finish(&mut writer).unwrap();

for batch in bit_compact::batch::ChunkedReader::new(&reader, 64) {
    let b = batch.unwrap(); // Vec<Vec<f32>> len 64
}

Validation

use bit_compact::validate;
let rep = validate::validate("vectors.btcp").unwrap();
println!("{}", rep.summary());
assert!(rep.checksum_valid && rep.row_ids_monotonic);
assert!(validate::quick_check("vectors.btcp").unwrap());

Transforms

use bit_compact::{Normalizer, Centering, Standardizer, Transform};

let chain = bit_compact::Chain::new(cent, n).unwrap();
let out = chain.transform_vector(&query).unwrap();

4× on payload (f32 4B → u8 1B), header 32B + meta 2*dims*4 + footer count*8+32 overhead
